## I. aiflow 知识层「架子」验收（若自建 / 桥接）

> 学 Gaia 架子时，用本表验收 aiflow 或「aiflow Tool → Gaia」方案。

### I-1 数据模型

- [x] I1 知识库表（id / name / owner / status / 策略配置）— `ai_knowledge_base`
- [x] I2 文档表（库 id / 文件元数据 / 启用状态 / 索引状态）— `ai_knowledge_document`（架子：text 源）
- [x] I3 分段或索引任务表（可追踪失败）— `ai_knowledge_chunk`（无独立索引任务表；失败记 document.error）
- [x] I4 应用-知识库绑定表（含环境：生产/测试）— `ai_knowledge_binding`
- [-] I5 召回日志或命中统计（至少能支撑月报）— 架子不做

### I-2 接口能力

- [x] I6 创建 / 更新 / 归档知识库 API — createBase / updateBase / archiveBase
- [~] I7 上传文档 / 启用禁用 API — ingestText / ingestFile（本地纯文本）+ setDocumentEnabled；无 HTTP 上传 UI
- [x] I8 检索 API（query → chunks + score + 来源文档）— SimpleKeywordRetriever
- [x] I9 绑定查询 API（某应用绑了哪些库）— bind / bindingsOf
- [-] I10 权限：业务角色可写内容，开发角色管管道 — 宿主挂 guard；架子未强制

### I-3 与现有 aiflow 模块衔接

- [x] I11 Agent 可通过 Tool 调用检索（带权限门 `tool:…`）— `KnowledgeRetrieveTool`（门建议 `tool:knowledge.retrieve`）
- [x] I12 Workflow 的 llm/task 节点可注入检索上下文 — `RetrieveKnowledgeTask` + `KnowledgeContext`
- [-] I13 计费：检索 / embedding 是否走 Credit（产品已决策）— 后置
- [x] I14 示例脚本或 demo：`examples/` 或 FMS CLI 可跑通检索 — `examples/knowledge.php`
- [x] I15 文档：`docs/integration.md` 含知识库接入一节

### I-4 非功能

- [-] I16 检索 P95 延迟有基线 — 架子不做
- [x] I17 密钥与模型配置不进仓库 — 架子无密钥依赖
