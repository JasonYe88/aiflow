## Epic

**标题：** `[知识库] Gaia 默认空间止血与运营分工落地`

**描述：**
```
背景：
- 默认空间存在 7 个知识库（分类匹配 + 人事行政/IT 客服），但普通角色看不到「知识库」菜单。
- 调研发现生产库文档存在大面积 disabled；分类库存在跨平台串绑风险；存在空壳库与重复库。
- 现行分工是「开发维护知识、业务只使用应用」，导致内容无法自助更新、故障无法自助排查。

目标：
1) 生产知识恢复可用或正式下线有说明
2) 串绑/空壳/重复库清干净
3) 业务/产品/测试具备改库与验收能力
4) 对齐运营制度（见 docs/knowledge/ops-policy.md）

验收：
- checklist H1～H6 全部勾选
- A1～A4、A6 至少完成（Owner + 入口权限 + 开发退出日常传文档）
```

## 任务列表（可直接建单）

### P0 · 本周

#### TASK-H1
- **标题：** `[知识库][P0] 排查并处理生产库文档大面积 disabled`
- **建议指派：** 平台开发（主）+ 各库业务 Owner（确认是否应恢复）
- **类型：** 缺陷 / 技术任务
- **描述：**
```
现象：美客多分类、制度或行政QA、系统操作手册、IT系统文档等库内文档 indexing 已完成，但 enabled=false / display_status=disabled。
影响：工作室应用仍挂库，但检索可能空召回，表现为「AI 乱答/不答」。
动作：
1. 确认是误操作全量禁用，还是刻意下线
2. 若误操作：按库恢复启用，并做召回冒烟
3. 若刻意下线：书面说明原因、影响应用清单、替代方案
验收：每个生产库要么「文档已启用且召回冒烟通过」，要么「正式下线说明已贴到需求评论」
关联检查项：H1
```

#### TASK-H2
- **标题：** `[知识库][P0] 清理美客多分类库与 TikTok 应用的错误/可疑串绑`
- **建议指派：** 产品经理（拍板）+ 平台开发（改绑定）+ 刊登运营（验收）
- **类型：** 缺陷
- **描述：**
```
现象：知识库「美客多分类」related-apps 含「TikTop 分类匹配」与「美客多平台-分类匹配映射」。
风险：跨平台分类答错，直接伤害刊登质量。
动作：
1. 核对 TikTok 应用应绑定「TikTok分类匹配」库
2. 美客多应用仅保留美客多库
3. 改绑后各跑 10 条分类问法冒烟
验收：绑定关系表更新；串绑清零；冒烟记录贴评论
关联检查项：H2、E2
```

#### TASK-H5
- **标题：** `[知识库][P0] 为业务Owner/产品/测试开通默认空间知识库入口权限`
- **建议指派：** Gaia 管理员 / 平台开发
- **类型：** 配置变更
- **描述：**
```
现象：角色 normal 在默认空间无「知识库」导航，/datasets 被重定向到工作室；个人空间有入口但无库。
目标：业务 Owner、产品、测试能看到并编辑负责的库；普通使用者仍可只用不改库。
动作：
1. 评估 dataset_operator / 工作区角色方案
2. 开通最小权限并留审批记录
3. 若组织决定「普通成员永不开放」：书面否决 + 改运营流程（所有变更走提工单）
验收：目标账号登录默认空间可见知识库；A4/A7 可勾选
关联检查项：H5、A4、A7
```
